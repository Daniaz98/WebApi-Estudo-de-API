
# Criando uma API .NET

- Um projeto de estudo de criação de APIs em .NET, no qual foram abordados conceitos para sua criação, sendo uma API simples, de um CRUD de cadastro de pessoas.
- Tendo sido guiado por um tutorial de introdução ao .NET
- Segue link do tutorial: https://www.youtube.com/watch?v=Z94fONesCjY&list=PLMFE0Mu3BVy5KeaTk0eGOXPOxyl1yIxOA&index=1&t=3315s&ab_channel=CristianWilliamDev
 
 
## Aprendizados

- Criação de rotas para Criar, Atualizar, Ler e Excluir, utilizando-se dos verbos REST
- Realização de testes com o Swagger e Postman
- Análise das requisições no navegador
